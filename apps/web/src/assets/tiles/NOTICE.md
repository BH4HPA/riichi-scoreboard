# 牌图来源

本目录 37 张 SVG 来自 [lietxia/mahjong_graphic](https://github.com/lietxia/mahjong_graphic)
（`Vectors 矢量图/SVG`，扁平风格），原样引入，未做修改。

- 许可：仓库 `LICENSE` 为 M+ 字型式自由许可（允许商用与修改，无署名要求，按原样提供）。
- 上游声明部分图形来源于 [SyaoranHinata/I.Mahjong](https://github.com/SyaoranHinata/I.Mahjong)。

代码中通过 `features/hand/TileFace.tsx` 以 `<img>` 引用，编码映射见 `packages/core/src/types/tiles.ts`。
